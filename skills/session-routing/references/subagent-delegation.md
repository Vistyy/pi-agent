# Temporary Managed Agent Delegation

## 1. Prepare the assignment

Assign one bounded read-only supporting slice.
State its requested local result, relevant starting anchors and constraints, and a stopping condition when one is useful.
Include enough parent context to make the slice coherent without transferring the user outcome or its consequential decisions.
Scope the slice by the result it must return, not by an arbitrary limit on connected sources or steps.
A helper may reason within its slice, but the parent retains interpretation of what the result means for the overall outcome.
Give concurrent helpers non-overlapping slices unless independent corroboration is intentional.
Pass skills that match the slice when the delegation interface supports them.

This step is complete when the assignment has one owner and a clear result boundary.

## 2. Coordinate the work

Do not duplicate the exact active helper slice.
Continue useful parent work that does not duplicate that slice.
Send context-local guidance or follow-up work to the same helper.
Use another helper only for a separate slice or intentional independent corroboration.
Do not poll helper status when completion notification can resume the parent.

This step is complete when every active slice has one owner.

## 3. Apply the report

Treat the report as an input, not an authoritative conclusion.
Evaluate its evidence, reasoning, uncertainty, and limits in the context of the parent-owned outcome.
Inspect material source evidence when needed to support the parent conclusion or resolve a conflict.
For a material gap likely to be resolved from the helper's existing context, send one bounded follow-up with an explicit stopping condition.
If the gap remains, report its limit instead of broadening the helper into the parent decision.

This step is complete when the parent can integrate the result or has made each unresolved material gap explicit.
