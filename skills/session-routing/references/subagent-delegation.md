# Temporary Managed Agent Delegation

## 1. Prepare the assignment

Assign one bounded read-only deliverable.
State one requested result, the user outcome, accepted constraints, relevant decisions, known starting anchors, a stopping condition, and the evidence the main session needs.
Do not explore sources only to prepare the assignment or ask the agent to override its read-only boundary.
Give concurrent agents disjoint scopes unless independent corroboration is intentional.
Pass the skills that match the assignment when the delegation interface supports them.

The agent may stop when continuing requires guessing, broader scope, mutation, or a parent decision.
Request a compact report containing the applicable information:

- the result or recommendation;
- exact source paths and relevant identifiers;
- material evidence and reasoning;
- uncertainty and evidence limits;
- the specific blocker, question, conflict, risk, or parent decision required.

Request full file contents, exhaustive output, or exploratory history only when the main-session decision requires them.

This step is complete when the assignment has one owner and a decision-ready response contract.

## 2. Coordinate the work

Do not independently investigate or verify a scope while its temporary managed agent owns it.
Continue with disjoint work when it does not depend on the delegated result.
Wait when the next action requires the result.
Send context-local follow-up work to the same agent.
Use another agent only for a separate scope or intentional independent corroboration.

This step is complete when every active scope has one owner.

## 3. Apply the report

Use the report as evidence for the main-session decision.
Treat a stopped assignment with a clear evidence limit or parent question as a valid result.
For a material source-local gap likely to be resolved by follow-up, send the same agent one bounded follow-up with an explicit stopping condition.
End at resolution or the stopping condition; if the gap remains, report its evidence limit, and do not extend the follow-up for unrelated evidence.
Inspect an exact source in the main session only when synthesis or conflicting evidence requires it.
Do not repeat delegated exploration.

This step is complete when the main session can integrate the result or has reported each unresolved material gap and its evidence limit.
